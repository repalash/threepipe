# Create BaseGroundPlugin Example

## Summary

BaseGroundPlugin has a doc page (`website/plugin/BaseGroundPlugin.md`) but no dedicated example. The SSContactShadowsPlugin doc previously linked to a non-existent `#base-ground-plugin` example (fixed to link to `#contact-shadow-ground-plugin` instead).

## Action

Create `examples/base-ground-plugin/` demonstrating:
- Adding BaseGroundPlugin to a viewer
- Loading a model with auto-positioned ground
- Configuring size, yOffset, material properties
- Camera limit above ground
- Custom geometry (e.g., circular ground)

Then add an Example link to the header of `website/plugin/BaseGroundPlugin.md`.
