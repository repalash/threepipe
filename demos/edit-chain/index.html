edit-chain: thirty edits on one mesh, and nothing else

An EditHero-style chain (arXiv 2610.02298) on threepipe's modelling command API: a 16-sided cylinder becomes a chess rook in 30 commands, and side chains cover the rest of the command table. After every step the harness checks that the step did what it claimed (did), that nothing outside its claim changed, bit for bit (locality), that the mesh validates and gained no non-manifold edges or flipped windings (manifold), that undo restores the document exactly and redo brings the edit back (undo), and that a second run in a fresh page gives the same document (determinism). Re-run with npm run demo:edit-chain; this page reads results.json.
