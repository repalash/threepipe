Mesh Edit Mode

Getting started
1. Click the cube to select it
2. Press Tab to enter edit mode
3. Click vertices to select them
Keys
Tab enter / leave edit mode
1 / 2 / 3 vertex / edge / face mode
A select all   Alt+A none
Ctrl+I invert   L select linked
Shift+click extend selection
drag box select, middle-drag or Alt+drag orbit
Ctrl+Z undo, Ctrl+Shift+Z redo
Transform
drag the gizmo, or G / R / S move / rotate / scale
E extrude the selection
X / Y / Z lock to an axis, again for local
Shift+X/Y/Z lock to a plane, MMB picks the axis
type digits or = expression for an exact value
Ctrl snap, Shift precision, wheel proportional size
click or Enter confirm, Esc cancel
Reference
Drag image files onto the viewport, then drag and resize the panels.
