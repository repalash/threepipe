# Changelog

## 0.1.0

- First shell: registry interfaces (`src/registry.ts`), `LegacyEditorEngine` adapter over the
  existing mesh-edit / modelling / picking / undo plugins, `EditorViewportPlugin` (grid, axes,
  orthographic and axis views, framing, shading), and the React layout: header menus, mode switch,
  select-mode buttons, tool shelf, outliner, properties (Object / Mesh / Modifiers / Material),
  last-operation panel, status bar, command palette (Ctrl/Cmd+K, F3), viewport and outliner
  context menus, undo history, shortcuts and about dialogs, toasts.
